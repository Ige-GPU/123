아마존 직구 주소 입력 방법

Address Line 1, City, State… 어디에 뭘 넣어야 할까?

아마존(amazon.com) 배송지 입력 화면은 한국 주소 체계와 순서가 달라서 처음 직구할 때 가장 많이 막히는 부분입니다. 이 가이드는 서울특별시 중구 세종대로 110, 101동 1001호를 예시로 각 칸에 들어갈 내용을 보여드립니다.

1. 먼저 주소를 영문으로 변환하세요

영문주소 변환기에 한글 주소를 입력하면 아마존 입력칸에 맞게 자동으로 나눠서 보여드립니다. 변환 결과에서 "쇼핑몰 입력 양식으로 보기"를 누르세요.

2. 아마존 입력칸별 작성법

  • Full name — 여권 영문 이름 (예: HONG GILDONG)
  • Phone number — 010-1234-5678 → +82-10-1234-5678 (맨 앞 0 제거)
  • Address Line 1 — 도로명 주소: 110 Sejong-daero
  • Address Line 2 — 동·호수: Apt 101-1001 (없으면 비워둠)
  • City — 시/군/구: Jung-gu
  • State / Province / Region — 시/도: Seoul
  • ZIP Code — 5자리 우편번호: 04524
  • Country — South Korea

3. 자주 하는 실수

  • 주소를 통째로 Address Line 1에 다 넣으면 라벨이 잘려 배송 사고가 날 수 있습니다. 칸을 나눠 쓰세요.
  • 동·호수를 빠뜨리면 아파트 단지까지만 도착합니다. Address Line 2를 꼭 채우세요.
  • State에 "Korea"를 쓰면 안 됩니다. 시/도(Seoul, Gyeonggi-do 등)를 넣으세요.

4. 개인통관고유부호

한국으로 직배송 시 통관을 위해 개인통관고유부호(P로 시작하는 13자리)가 필요할 수 있습니다. 발급 방법은 개인통관고유부호 가이드를 참고하세요.
