알리익스프레스 주소 쓰는법

한 번만 제대로 설정하면 계속 쓸 수 있습니다

알리익스프레스는 한국 배송이 많아 주소 입력이 비교적 한국 친화적이지만, 여전히 영문(로마자) 표기를 권장합니다. 한글로 쓰면 국내 택배 단계에서는 문제가 없으나 중국 출고·통관 단계에서 지연되는 경우가 있습니다.

입력칸별 작성법

예시 주소: 경기도 성남시 분당구 판교역로 166, 101동 202호

  • Contact name — 영문 이름 (예: KIM MINSU)
  • Country/Region — South Korea
  • Province — 시/도: Gyeonggi-do
  • City — 시/군/구: Seongnam-si Bundang-gu
  • Street Address — 166 Pangyoyeok-ro, Apt 101-202
  • ZIP Code — 13529
  • Mobile — +82 10-1234-5678

영문주소 변환기에서 주소를 검색한 뒤 "쇼핑몰 입력 양식으로 보기 → 알리익스프레스" 탭을 누르면 위 칸에 맞게 자동으로 나눠 줍니다.

개인통관고유부호 입력

알리익스프레스는 한국 배송 시 개인통관고유부호(PCCC)를 요구합니다. 주소 설정 화면 하단의 Personal Customs Clearance Code 칸에 P로 시작하는 13자리를 입력하세요. 아직 없다면 발급 방법 가이드를 참고하세요. 발급은 무료이며 5분이면 끝납니다.

배송이 안 올 때 체크리스트

  • 우편번호 5자리가 정확한지 (구 6자리 우편번호를 쓰면 안 됩니다)
  • 통관부호의 이름·전화번호가 주문자 정보와 일치하는지
  • 전화번호가 +82 형식으로 입력되었는지
