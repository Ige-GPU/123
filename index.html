영문주소 변환기

한글 주소를 입력하면 국제 표준 영문 주소로 바꿔드립니다

도로명주소·지번주소·건물명 모두 검색 가능. 검색 결과에서 아마존·알리 입력 양식으로 바로 변환됩니다.

영문주소는 언제 필요한가요?

  • 해외직구 — 아마존, 이베이, 알리익스프레스 등 해외 쇼핑몰 배송지 입력
  • 국제배송·EMS — 해외에서 한국으로 물건을 받을 때
  • 비자·유학 서류 — 영문 거주지 증명이 필요한 각종 서류
  • 해외 결제 빌링 주소 — 해외 카드 결제 시 청구지 주소

영문주소 쓰는 법

한국식 주소는 큰 단위(시/도)부터 쓰지만, 영문주소는 반대로 작은 단위부터 씁니다. 예를 들어 서울특별시 중구 세종대로 110은 110 Sejong-daero, Jung-gu, Seoul이 됩니다. 상세주소(동·호수)는 맨 앞에 붙입니다. 예) #101-1001, 110 Sejong-daero, …

해외직구 가이드

  • 아마존 직구 주소 입력 방법 (단계별)
  • 알리익스프레스 배송지 설정 방법
  • 개인통관고유부호 발급 방법과 입력 위치

자주 묻는 질문

변환 결과는 공식적인 주소인가요?

네. 행정안전부 도로명주소 공식 데이터(juso.go.kr)를 사용하므로 정부에서 고시한 공식 영문 표기입니다.

아파트 동·호수는 어떻게 쓰나요?

검색 결과의 영문주소 앞에 직접 붙여 쓰면 됩니다. 예) Apt 102-1504, 를 주소 맨 앞에 추가.

우편번호도 알 수 있나요?

네, 변환 결과에 5자리 우편번호가 함께 표시됩니다.

주소 데이터 제공: 행정안전부 도로명주소 안내시스템 (juso.go.kr)
