개인통관고유부호 발급 방법

해외직구 필수 — 무료 발급, 5분 소요

개인통관고유부호란?

개인통관고유부호(PCCC, Personal Customs Clearance Code)는 해외직구 물품 통관 시 주민등록번호 대신 사용하는 P로 시작하는 13자리 번호입니다. 한 번 발급받으면 평생 사용하며, 모든 해외직구 사이트에서 공통으로 씁니다.

발급 방법 (무료)

  1. 관세청 유니패스 개인통관고유부호 발급 페이지 접속 — unipass.customs.go.kr
  2. 휴대폰 본인인증 또는 공동인증서 인증
  3. 이름·전화번호 확인 후 발급 — 즉시 P 번호가 표시됩니다

모바일에서는 "관세청 개인통관고유부호" 검색으로 바로 접속할 수 있습니다.

이미 발급받았는데 번호를 잊어버렸다면

같은 유니패스 페이지에서 본인인증만 다시 하면 기존 번호를 조회할 수 있습니다. 재발급이 아니라 조회이므로 번호는 바뀌지 않습니다.

사이트별 입력 위치

  • 알리익스프레스 — 배송지 설정의 Personal Customs Clearance Code 칸. 알리 주소 설정 가이드 참고
  • 아마존 — 주문 후 배송대행지/직배송 통관 단계에서 요구. 아마존 주소 입력 가이드 참고
  • 아이허브 — 결제 단계에서 통관부호 입력칸이 표시됩니다

주의사항

  • 통관부호의 명의(이름·전화번호)는 주문자 정보와 일치해야 통관이 지연되지 않습니다.
  • 가족 명의로 주문할 경우 그 가족의 통관부호를 사용해야 합니다.
  • 타인에게 알려주면 명의도용 위험이 있으니 주의하세요.
